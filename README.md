# 💈 BarberOS - Sistema de Gestión para Barberías

BarberOS es una plataforma web integral diseñada para la gestión, reserva de citas y administración de barberías modernas. Ofrece una experiencia premium para clientes, barberos y administradores.

## 🚀 Características Principales

- **Gestión de Reservas:** Permite a los clientes agendar citas seleccionando servicio, barbero, fecha y hora.
- **Panel de Administración (Hub):** Control total sobre clientes, barberos, métricas y estado del negocio.
- **Vista de Barbero:** Agenda personalizada para cada profesional de la barbería.
- **Diseño Premium:** Interfaz oscura elegante con acabados dorados (*obsidian & gold design system*).
- **Control de Estados:** Citas pendientes, confirmadas, completadas o canceladas en tiempo real.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18, TypeScript, Vite
- **Estilos:** Tailwind CSS, Radix UI, Lucide Icons
- **Enrutamiento:** React Router DOM
- **Estado:** Zustand, TanStack Query

## 💻 Instalación y Desarrollo Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/serduncant/barberos-hub.git
   cd barberos-hub
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Construir para producción:**
   ```bash
   npm run build
   ```
